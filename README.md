# Restaurant Stock Control

A modern inventory management dashboard for a restaurant, built with Next.js and Tailwind CSS.

## Features

- Secure login screen with role-based access
- Category dashboard for all restaurant stock zones
- Add staff members from the admin panel
- Quick stock +/- controls for each item
- Stocktake session modal with count snapshots
- Audit log for login activity
- Responsive dark/light UI

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.
